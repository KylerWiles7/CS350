# CS350 – Thermostat Project

## Project Overview

This project involved developing a thermostat system that monitors the current temperature and compares it to a user-defined setpoint. I worked on integrating hardware components and software functionality to create a system that allows users to adjust the desired temperature and switch between heating, cooling, and off modes. Through this project, I gained hands-on experience with hardware and software integration and learned how different components work together to create a functional embedded system.

## Technologies Used

- **C** – Used to implement the thermostat's logic and control functionality.
- **Microcontroller** – Used to execute the software and interface with the hardware components.
- **Temperature Sensor** – Used to monitor the current temperature.
- **Push Buttons** – Used to adjust the temperature setpoint and switch between operating modes.
- **Embedded Hardware** – Used to connect the physical components and support the thermostat's functionality.

## Project Features

### Temperature Monitoring

I worked on implementing functionality to monitor the current temperature and compare it to the thermostat's setpoint. This allowed the system to respond to temperature changes based on the user's desired settings.

### Setpoint Adjustment

I implemented button functionality that allows users to increase or decrease the thermostat's setpoint. This provided a simple way for users to control the desired temperature.

### Operating Modes

I worked on implementing different operating modes that allow users to switch between heating, cooling, and off. This functionality helped me understand how user input can control the behavior of an embedded system.

### Hardware and Software Integration

I connected the hardware components and integrated them with the software to create a functional thermostat. This involved understanding how the physical components interact with the program and how the system responds to user input.
